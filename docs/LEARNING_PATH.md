# LEARNING_PATH.md

# AMGCR Earthquake Research - Learning Path

## Purpose

This document provides the recommended learning sequence for the AMGCR Earthquake Research project. It is intended to help beginners build knowledge gradually while implementing the project.

---

# Learning Philosophy

Learn → Understand → Implement → Verify → Improve

Do not skip concepts. Each phase builds on the previous one.

---

# Phase 1 — Development Environment

## Objectives
- Understand the project structure.
- Install Python.
- Create a virtual environment.
- Install project dependencies.
- Learn basic Git commands.

### Deliverables
- Working development environment
- Successful ObsPy installation
