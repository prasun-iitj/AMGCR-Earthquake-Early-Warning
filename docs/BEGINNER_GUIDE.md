# BEGINNER_GUIDE.md

# AMGCR Earthquake Research - Beginner Guide

## Purpose

This guide is intended for beginners who are new to earthquakes, seismology,
Python, and ObsPy. It explains the concepts required for this project in a
simple, step-by-step manner.

---

# What is this Project?

The goal of this project is to build a complete Earthquake Early Warning
research pipeline using real earthquake data.

Instead of only learning theory, we will learn by building the project from
scratch.

---

# What You Will Learn

- Basics of earthquakes
- Seismic waves
- Earthquake catalogues
- Seismic stations
- Waveforms
- ObsPy fundamentals
- Data preprocessing
- Feature extraction
- Introduction to AI for earthquake research

# Best Practices

- Understand every concept before coding.
- Read official documentation.
- Keep notes during learning.
- Experiment with small examples.
- Ask questions whenever something is unclear.
