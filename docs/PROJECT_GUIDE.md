# AMGCR Earthquake Research - Project Guide

## Purpose

This document is the master operating guide for the **AMGCR_Earthquake_Research** repository.

It should be read by every developer, researcher, or AI coding assistant before making changes to the project.

---

# Project Vision

Develop a complete, reproducible Earthquake Early Warning System (EEWS) research pipeline using Python and ObsPy, starting from the fundamentals of seismology through to data processing and future AI/ML experimentation.

---

# Project Goals

- Learn earthquake science from first principles.
- Retrieve earthquake catalogues from FDSN services.
- Download seismic waveforms.
- Process and visualise waveform data.
- Build a modular research codebase.
- Reproduce methods from the reference research paper.
- Extend the work with machine learning.

# Repository Rules

1. Keep the project modular.
2. One responsibility per Python module.
3. Avoid hard-coded paths.
4. Document every milestone.
5. Maintain reproducibility.
6. Keep documentation updated with implementation.

---

# Coding Standards

- Follow PEP 8.
- Use meaningful variable and function names.
- Add docstrings to public functions.
- Prefer configuration files over hard-coded values.
- Write reusable code.
